# Site da Atual Sistema de Ensino

Site feito pela PineWeb. Arquivo único (`index.html`), publicado no GitHub Pages.

## Como trocar as fotos

Suba a foto na pasta `img/` com o nome exato abaixo (formato `.jpg`, de preferência na horizontal e com até 300 KB). A página encaixa a foto sozinha; enquanto o arquivo não existir, aparece o espaço vazio.

| Arquivo | Onde aparece |
|---|---|
| `img/fachada.jpg` | Topo, foto da fachada |
| `img/aula.jpg` | Topo, alunos em aula |
| `img/evento.jpg` | Topo, evento da escola |
| `img/sala.jpg` | Galeria, sala de aula |
| `img/lab.jpg` | Galeria, laboratório ou aula prática |
| `img/aulao.jpg` | Galeria, aulão de redação |
| `img/festa.jpg` | Galeria, festa ou evento |
| `img/equipe.jpg` | Galeria, professores |
| `img/formatura.jpg` | Galeria, formatura |

## Números e depoimentos a confirmar

Os números (anos de história, cidades, aprovações, nota de redação) e os três depoimentos são exemplos marcados na página. Trocar pelos dados reais da escola antes de divulgar.
